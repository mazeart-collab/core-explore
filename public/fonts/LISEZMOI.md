# Polices de la charte CORE

Déposez ici les fichiers web des polices sous licence (format .woff2 de préférence) :

- `Hagrid.woff2` : grands titres (titre de page, accroche de l'accueil)
- `Agrandir.woff2` : intertitres (sections, cartes)

Tant qu'un fichier manque, le site utilise Montserrat à la place.
